# NewLife.Office 需求文档

> 版本：v2.2 | 日期：2026-08-10
> 完成状态在[功能清单](功能清单.md)中追踪，详细设计在[架构设计](架构设计.md)中展开。

## 1. 背景与愿景

### 1.1 系统定位

NewLife.Office 是一个功能全面的 .NET 办公自动化库，覆盖 **Excel（xlsx/xls）、Word（docx/doc）、PPT（pptx/ppt）、PDF**、Markdown、RTF、ODS、Email（eml/msg）、iCalendar、vCard、EPUB、XPS 等主流文档格式，以及基于 OLE2/BIFF8 的老式二进制格式（.xls/.doc/.ppt），并配套 **Rendering** 渲染扩展包（文档页面 → 图片）。

**核心定位**：以 MIT 开源协议为社区提供主流办公文档的**全面操作能力**，覆盖创建、读取、编辑、模板填充、合并拆分、格式转换等常见业务场景，让开发者无需依赖商业库即可完成绝大多数办公自动化任务。

**设计原则**：
- **零外部依赖**：主库仅依赖 NewLife.Core，直接操作 Open XML（ZIP + XML）/ PDF / OLE2 文件结构
- **性能优先**：避免中间层开销，直接解析底层结构
- **统一 API**：各格式 API 风格一致，学习成本低

> 说明：CSV 读写操作已由 NewLife.Core 中的 `CsvFile` 类提供支持，本项目不重复实现。

### 1.2 愿景

NewLife.Office 的目标是成为 .NET 生态中**功能全面、零依赖、MIT 许可**的办公自动化首选库：

- **全面覆盖主流格式**：以免费开源方式覆盖四大主流办公格式 + 十种轻量格式，让开发者摆脱商业许可困扰
- **Markdown 全格式转换中枢**：作为 .NET 生态中唯一的办公文档 ↔ Markdown 双向转换中枢，为 NewLife.AI / ChatAI 知识库喂入提供统一入口
- **与 NewLife 生态深度集成**：与 NewLife.Core / NewLife.Cube 等组件无缝配合，覆盖报表导出、模板报告、数据导入等企业管理后台高频场景

## 3. 功能需求

### 3.1 M — Excel（xlsx/xls）

**文件读写**
- 读取和写入 xlsx 格式（Open XML，直接操作 ZIP + XML）
- 读取和写入 xls 格式（OLE2/BIFF8，兼容 Excel 97-2003）
- 多工作表支持（按名称/索引访问）、共享字符串处理、流式读写（低内存）

**单元格与样式**
- 单元格类型自动识别（文本/数值/日期/布尔/百分比）、长数字保留文本（防科学计数法）、身份证号/前导零保护
- 字体（名称/大小/粗体/斜体/下划线/颜色）、背景填充色、边框（含四边独立/对角线）
- 对齐方式（水平/垂直/自动换行）、自定义数字格式（`#,##0.00`、`yyyy-MM-dd`）
- 条件格式（数值条件高亮、数据条、色阶、图标集、自定义公式）
- 富文本（单元格内多种格式混排）、渐变填充、图案填充、字体增强（删除线/上标/下标）

**布局与操作**
- 列宽（自动估算/手动）、行高（手动/自动）、合并单元格（读写）
- 冻结窗格（行/列/行列组合）、自动筛选、隐藏行/列、分组折叠（大纲级别）
- 文本旋转、缩进、缩小以填充

**内容元素与高级能力**
- 公式（读写，不含计算引擎）、超链接（URL/邮箱/内部跳转）
- 数据验证（下拉列表、数值/日期范围）、图片插入与读取
- 图表（柱状/条形/折线/饼/环形/面积/散点/气泡，创建与读取）
- 数据透视表（基本创建与读取）、迷你图（Sparklines）
- 对象映射导入/导出（`IEnumerable<T>` ↔ Excel，支持 `[DisplayName]`/`[Description]`）
- DataTable 导入/导出、模板填充（占位符替换 + 列表区域扩展）
- 命名范围（Defined Names）、结构化表格（Table，60+ 内置样式）
- 工作表标签颜色、工作簿保护（密码哈希）、计算选项
- 分页符、打印区域、文档属性（core.xml）
- 页面/打印设置（方向/纸张/边距/页眉页脚/打印标题行）

**xls 二进制（BIFF8）**
- BiffReader：读取工作表数据/样式/共享字符串/合并区域/超链接/列宽
- BiffWriter：写入样式（字体/填充/边框/颜色/数字格式）、合并单元格、冻结窗格、行高、超链接、自动筛选、页面设置、页眉页脚、默认列宽、公式

**批注增强（M26）**
- 批注富文本：单元格批注支持多段文本与样式（加粗/斜体/颜色/字号），生成富文本 comment XML（对标 EPPlus）
- 批注读取增强：还原批注富文本段与作者信息

**线程化批注（M27，对标 EPPlus/Aspose.Cells）**
- 线程化批注写入：`AddThreadedComment` 生成 personList + commentList 部件（作者/时间/回复层级），对话式批注
- 线程化批注读取：还原批注对话线程（作者/时间/正文/回复关系）

**切片器（M28，对标 EPPlus/Aspose.Cells）**
- 切片器写入：`AddSlicer` 关联数据透视表/结构化表格，生成 slicerCache + slicer XML（列/值范围/样式）
- 切片器读取：还原切片器列表（名称/标题/关联缓存/按钮列）

**读取健壮性（M29，真实世界文件）**
- 1904 日期系统：解析 workbookPr date1904，Mac Excel 日期正确换算；修复 1900 系统虚构闰日（序列60）与 1900-03 之前日期差一天的缺陷
- 错误/ISO 日期单元格：`t="e"` 保持错误字符串不做数字转换，`t="d"` 解析为 DateTime
- 富文本共享字符串：跳过音标节点，仅拼接 `<t>` 文本
- 主题色解析：`ResolveThemeColor` 将 `theme:N`（含 tint）解析为实际 RGB
- 隐藏行列读取、缺失部件容错（无 sharedStrings/styles/workbook 仍可读取）

**隐藏行列与批注模型（M30）**
- `SetRowHidden`/`SetColumnHidden` 隐藏行列写入，WriteExcel 往返
- `Worksheet.Comments` 升级为 `Comment` 模型（文本/作者/宽高/可见性/偏移），读写 vmlDrawing 尺寸可见性

**流式读取（M31）**
- ReadRows/ReadObjects/ReadDataTable 基于 XmlReader 流式解析，大文件内存平坦（10万行约 1s）

**xls 读写增强（M32）**
- BiffReader：合并单元格（MERGEDCELLS）、页面设置（SETUP/HEADER/FOOTER）、工作表保护（PROTECT）、数据验证（DV）读取
- BiffWriter：`ProtectSheet` 工作表保护（15位 XOR 密码哈希）、`AddDropdownValidation` 下拉列表验证（DV+DVAL）

### 3.2 W — Word（docx/doc）

**高保真读写架构（L3）**
- `WordReader.ReadDocument()` 完整对象图（段落/表格/图片/页眉页脚/批注/样式），`WordWriter.Save(doc)` 写回
- 模型 + RawXml 透传兜底（每个 `Element` 保留原始 OuterXml，未建模属性不丢失）
- ZIP 部件完整透传（styles/numbering/settings/header/footer/footnotes/endnotes/theme/fonts 原样保留）
- 往返原则：读入 → 不改动 → 写出 = 字节级等价；读入 → 修改 → 写出 = 视觉级等价

**文本与排版**
- Run 级格式：粗体/斜体/下划线（多种样式）/字体/字号/颜色/上标/下标/删除线/字符间距/字符缩放/发光/阴影
- 布尔格式三态（`Boolean?`）：`w:val="0"` 显式关闭继承格式；高亮/小型大写/全大写/隐藏文字/东亚字体/语言
- 段落级格式：标题（Heading 1-6）、对齐、缩进（twips）、段前段后间距、行距（百分比）、背景色、边框（四边独立）、制表位、分页符
- 列表：无序/有序/多级嵌套（基于 numbering.xml numId→numFmt 映射精确判定）、有序列表起始号、`Paragraph.NumId` 写回保真
- 分页控制：keepNext/keepLines/widowControl 孤行控制、首字下沉
- 查找替换：`Document.FindText`/`ReplaceText`（跨 Run 匹配保留首 Run 格式，忽略大小写/整词，覆盖正文/表格/页眉页脚/文本框）

**页面与布局**
- 页面尺寸/方向、页边距（twips）
- 页眉（default/first/even 三种类型）、页脚（含页码占位符），富文本页眉页脚（`Document.Headers/Footers` 模型读写）
- 奇偶页不同/首页不同页眉页脚、多节页面设置（`Section` 模型按 sectPr 切分读写）、分栏（ColumnCount/ColumnSpacing）
- 行号、页面边框、文字水印

**表格**
- 创建/读取（Table 模型）、单元格合并（ColSpan/RowSpan + gridSpan/vMerge）
- 边框样式、单元格背景色、表头行样式、斑马纹、列宽、水平对齐、单元格垂直对齐
- 跨页标题行重复（RawXml 兜底）、嵌套表格（RawXml 兜底）

**图片与绘图**
- 插入图片（PNG/JPEG，EMU/厘米尺寸控制）、图片提取（二进制 + 扩展名）
- SVG/文本框/形状（RawXml 兜底）、段落内嵌图片（RawXml 兜底）
- 文本框模型（`Paragraph.TextBoxes`）：读取文本框内容段落，`FindText`/`ReplaceText` 覆盖且替换后保存持久化（形状保留）
- `ReadParagraphs` 文本框文本去重（与 Word 原生行为一致）

**导航与引用**
- 超链接（URL/邮箱 + 关系管理）、书签（读写双向）、目录 TOC（RawXml 兜底）
- 脚注/尾注：模型级读取（`Footnote` 模型，Id/Text/Paragraphs，解析 footnotes.xml/endnotes.xml）+ 部件透传保留、内部交叉引用（REF 域引用书签显示页码）

**文档属性与保护**
- 文档属性（Title/Author/Subject/Description/Created，core.xml 读写）
- 自定义属性、文档变量（settings.xml docVars）
- 只读保护（可设密码）、AES-128 文档加密（`WordEncryptor`，ECMA-376 Agile Encryption）

**高级内容**
- 批注（Comment 模型，读/保留/写回，含作者/日期/内容/范围）
- 域代码（MERGEFIELD/DOCPROPERTY/PAGE/NUMPAGES/DATE 等，RawXml 兜底）
- 内容控件 SDT（RichText/ComboBox/PlainText/Date/DropDownList 读写）
- 邮件合并（`AppendMergeField` + `WordTemplate.MailMerge` 单/多记录）
- 自定义 XML 部件（customXml/item*.xml）、公式/图表/嵌入对象/SmartArt（透传保留）

**对象映射与模板填充**
- `WriteObjects<T>()` 对象集合 → 表格（支持嵌套对象属性展开）
- 模板填充：`{{Key}}` 占位符、表格区域（`{{#List}}`...`{{/List}}`）、图片占位符、对象属性自动映射、XML 拆分占位符合并

**格式转换与导出**
- docx → HTML（语义化：段落→`<p>`、表格→`<table>`、标题→`<h1>`-`<h6>`）
- docx → PDF（内容映射型，纯 C#）
- docx → Markdown（`IMarkdownExtractable`，表格→GFM、图片→MD 图片）
- 页面渲染为图片（经 PDF 中转，由 Rendering 扩展包承接）

**doc 二进制（MS-DOC）**
- DocReader：提取纯文本 + 段落结构（OLE2 容器）
- 带格式段落读取 `ReadParagraphsWithFormat()`：基于 PlcBte + CHPX/PAPX 解析粗体/斜体/删除线/字号/字体/颜色/对齐/缩进/列表级别，支持 WordDocument 与 1Table/0Table 流，无格式表回退纯文本
- **doc → docx 转换**（W20）：`DocReader.ToDocument()` 构建 Document 模型 + `SaveAsDocx()` 输出 docx，段落/表格交错顺序保留、常用格式映射

**竞品交叉兼容验证（W19）**
- F1 我写你读：NPOI 读取 `WordWriter` 生成文件（文本/格式/表格/图片/列表/页眉页脚）
- F2 你写我读：`WordReader` 读取 NPOI 生成文件
- OpenXmlValidator 规范校验：WordWriter 输出文件无 OOXML 规范错误（防 Word 修复提示）
- 真实文件回归库：`XUnitTest/Word/Fixtures/` 真实 Word 文件往返+校验

**修订追踪（W11，对标 Aspose.Words）**
- 修订记录模型级读取：解析 `w:ins`/`w:del` 还原修订列表（类型/作者/日期/文本），支持审计与 AI 知识库场景
- 保留现有 DocumentXml 透传能力，读取修订不破坏高保真往返

**自选图形创建（W12，对标 Open XML SDK/GemBox）**
- 形状对象创建：线条/矩形/圆/椭圆等自选图形（DrawingML 形状 + 位置/尺寸）
- 形状样式：填充色/线条色/线宽/旋转，支持精确坐标控制

**公式与图表创建（W13，对标 Open XML SDK/Aspose.Words）**
- OMML 数学公式创建：从结构化定义生成 OfficeMath XML（分数/上下标/根式/积分）
- 图表程序化创建：柱状/折线/饼图（DrawingML chart 部件 + 数据系列）

### 3.3 S — PPT（pptx/ppt）

**高保真读写架构（L2）**
- `PptxReader.ReadDocument()` 完整 `Presentation` 对象图，`PptxWriter.Save(stream, document)` 写回
- 完整对象模型 + 媒体/母版 ZIP 部件透传（图片/视频/字体字节一致）
- 模板加载（`new PptxWriter(templatePath)`）一行复用母版/版式/主题/嵌入字体
- 跨文件合并（`Merge()`/`CopySlideFrom()`，自动处理媒体冲突和关系 ID 重建）

**文本与排版**
- Run 级格式：四类字体独立设置（Latin/EastAsian/ComplexScript/Symbol）、字号、粗体/斜体/下划线、颜色（RGB 或主题色）、渐变文字、上标/下标、超链接
- 段落级格式：对齐、行距（百分比/固定磅值）、段前段后间距、项目符号、缩进级别（0-8）

**形状**
- 预设几何形状（30+ DrawingML 类型：rect/ellipse/roundRect/triangle/diamond/arrow 等）
- 填充色/线条色/线宽、精确位置（EMU，辅助方法支持厘米/磅/英寸互转）、旋转角度
- 形状克隆（模型级深拷贝）、组形状（GroupShape，统一 EMU 坐标，含组内图片）、连接器（直线/肘形/曲线，含箭头/虚线）
- 占位符识别（Role：title/subtitle/body 等）、形状渐变填充、翻转（FlipH/FlipV）
- Z-Order 图层控制、取消组合、文本方向/自动适应/内边距/虚线样式、图片圆角
- 形状属性双向读写：旋转/翻转/渐变/虚线/线宽/圆角/超链接（顶层与组内一致，往返保真）

**表格**
- 创建表格（列宽/首行表头高亮）、单元格独立样式（背景/字体/颜色/大小）
- 单元格合并（gridSpan/rowSpan/vMerge 读写双向）、四边独立边框
- 动态添加/删除行列、表格主题样式（TableStyleGuid 映射预定义 OOXML 样式）

**图表**
- 图表类型：柱状/条形/折线/饼/环形/面积/散点/雷达/股价/曲面
- 创建（Categories/Series/Title/位置）、读取（`ReadChartData`）、修改（`UpdateChartData`）
- 散点图数值 X 轴（c:xVal）、多系列数据、系列颜色定制
- 图表属性读回：系列颜色/XValues/数值轴 min/max/图例位置（`LegendPosition`）

**图片与媒体**
- 插入图片（PNG/JPEG，EMU/厘米）、批量提取、原地替换（`ReplaceImage`）
- 背景图片、SVG 图片（读写双向，asvg:svgBlip）、图片圆角
- 嵌入视频/音频（mp4/wmv/avi/mp3/wav/m4a，含缩略图，`PptVideo` 模型）

**母版、版式与主题**
- 从模板加载母版、编程式创建母版（`CreateMaster`）、跨文件复制母版
- 版式索引控制（`LayoutIndex`/`GetLayoutCount`/`GetLayoutName`）
- 主题色（6 个强调色）、母版/版式读取、原始 XML 访问

**幻灯片操作**
- 添加/删除/移动、同文件克隆、跨文件复制（含媒体自动复制）
- 多文件合并（静态 `Merge`）、演讲者备注、幻灯片编号/页脚、隐藏/显示、Section 分组

**动画与切换**
- 元素动画：进入（flyIn/appear/fade/zoom）、强调（pulse/spin）、退出三类
- 动画触发（单击/前一动画后/同时）、延迟/时长/序列/自动播放
- 幻灯片切换：fade/push/wipe/split/reveal/zoom/cover/dissolve/morph，含时长/方向/点击触发

**文档属性与保护**
- 文档属性（core.xml/app.xml 读写）、修改密码保护（SHA-512 modifyVerifier）

### 3.6 OLE — OLE2/CFB 基础层

OLE2（Compound File Binary，CFB）是 Microsoft Office 97-2003 时代所有二进制文档格式（.xls、.doc、.ppt、.msg）共用的容器格式，作为 xls/doc/ppt/msg 的共用基础层。

**容器读取**
- 解析复合文档头部（512 字节 Header）：版本、扇区大小、FAT/miniFAT 位置
- FAT（文件分配表）遍历：将散布磁盘的扇区链接为流（Stream）
- mini-FAT 处理：< 4096 字节的小流使用 mini-Stream
- 目录项（Directory Entry）遍历：按红黑树结构枚举所有 Storage / Stream
- 按名称访问流（如 "Workbook"、"WordDocument"、"\1CompObj"）
- 多版本兼容（v3 = 512B 扇区, v4 = 4096B 扇区）

**容器写入**
- 从零生成最小合法 CFB 文件、写入一个或多个 Stream、生成正确的 FAT/mini-FAT 和目录树

**BIFF8（xls）**
- 读取：BOF/EOF 记录、SST 共享字符串、DIMENSIONS/ROW/LABELSST/NUMBER/FORMULA/BLANK 核心记录、XF/FONT/FORMAT 样式记录、NAME/MERGEDCELLS/HYPERLINK
- 写入：BOF/SST/DIMENSIONS/ROW/单元格记录序列，支持字符串/数值/日期/布尔类型与基本样式

**MS-DOC（doc）**
- 提取 `WordDocument` 和 `1Table`/`0Table` 流，解析 FIB 获取结构偏移，遍历文本字符范围提取段落纯文本，识别基本段落格式

**MS-PPT（ppt）**
- 提取 `PowerPoint Document` 流，遍历「User Edit Atom」→「Persist Directory」定位最新版本，解析 `SlideAtom` + `TextBytesAtom`/`TextCharsAtom` 提取幻灯片文本

---

### 3.7 RT — RTF

**读取**
- 解析 RTF 控制字和控制词，提取段落文本、字体、颜色、段落格式
- 提取嵌入图片（WMF/EMF/PNG/JPEG）、提取表格（行/列/单元格文本）
- 读取文档属性（标题/作者/修订信息）

**写入**
- 生成合法 RTF 文件结构（RTF 头部 + 字体表 + 颜色表 + 内容）
- 支持段落格式（字体/大小/粗体/斜体/颜色/对齐/缩进/间距）
- 支持表格写入（基础行列结构）、图片嵌入（PNG/JPEG，十六进制编码）
- 文档属性写入

**模板填充**
- 基于 RTF 模板替换 `{{Key}}` 占位符，保留原有段落格式

---

### 3.8 OD — ODS（OpenDocument Spreadsheet）

ODS 是 LibreOffice / OpenOffice 的原生电子表格格式（ZIP + OpenDocument XML）。

**读取**
- 解析 `content.xml` 中的工作表数据（行/列/单元格）
- 单元格类型识别（string/float/date/boolean/formula）
- 读取合并单元格（`table:number-columns-spanned` / `table:number-rows-spanned`）
- 读取基础样式信息（字体/颜色/对齐）、对象映射导入（`IEnumerable<T>`/DataTable）

**写入**
- 生成合法 .ods 文件（`mimetype` + `content.xml` + `styles.xml` + ZIP 结构）
- 多工作表写入
- 基础单元格样式写入（字体粗体/斜体/大小/颜色、背景色、水平对齐）通过 `OdsCellStyle` + `OdsSheet.CellStyles` 注入，自动生成 `office:automatic-styles` 块
- 公式写入（OpenFormula 格式）、对象映射导出（`IEnumerable<T>` → ODS）

**与 Excel 互转**
- `.ods` → Excel 对象模型（`IEnumerable<Object[]>`）/ DataTable
- `.xlsx` → `.ods` 转换（限基础数据类型和样式）

---

### 3.9 EM — Email（EML/MSG）

**EML（RFC 5322 + MIME）**
- 解析 MIME 头部（From/To/Cc/Bcc/Subject/Date/Message-ID/Reply-To）
- 多部分解析（multipart/mixed/alternative/related）
- 正文提取（text/plain 和 text/html）、附件提取（文件名/内容类型/二进制数据）
- 内嵌图片（Content-ID 引用）、Q 编码/Base64 解码（RFC 2047）
- 创建 .eml（生成合法 MIME 邮件文档）

**MSG（Outlook Message，OLE2 容器）**
- 从 OLE2 容器提取 MAPI 属性（PR_SUBJECT/PR_BODY/PR_HTML_BODY/收件人列表）
- 提取附件（MAPI Attachment 对象）、读取发件人/收件人元数据
- 写入支持（低优先级）

---

### 3.10 IC — iCalendar（.ics）

**读取**
- 解析 iCalendar 3.0/4.0 格式（RFC 5545）
- 提取 VEVENT 组件（标题/描述/开始/结束时间/位置/重复规则/提醒）
- 提取 VTODO / VJOURNAL / VFREEBUSY 组件
- 时区处理（VTIMEZONE 组件，UTC 偏移）、重复规则（RRULE）解析（每日/每周/每月/每年）

**写入**
- 生成符合 RFC 5545 的 .ics 文件（含 75 字节行折叠）
- 创建 VEVENT（日程事件）、VTODO（待办事项）
- 支持重复规则（RRULE）写入、多日历条目导出

---

### 3.11 VC — vCard 联系人名片（.vcf）

**读取**
- 解析 vCard 3.0/4.0 格式（RFC 6350）
- 提取核心属性：FN/N（姓名）、ORG/TITLE（组织职位）、TEL（电话）、EMAIL、ADR（地址）、PHOTO（头像）、URL、NOTE、BDAY（生日）
- 分组（GROUP）属性解析、Base64 编码的 PHOTO 提取为字节数据

**写入**
- 生成符合 RFC 6350 的 .vcf 文件（vCard 4.0 优先，可降级到 3.0）
- 写入所有核心属性
- PHOTO 支持嵌入式 Base64 编码和 URL 引用两种模式、多联系人批量写入

---

### 3.12 EP — EPUB 电子书

**读取**
- 解析 EPUB 2/3 结构（ZIP + OPF/NCX/Nav Document）
- 读取书籍元数据（标题/作者/出版商/ISBN/语言/封面）
- 提取目录结构（NCX/Nav，章节层次）、提取各章节 HTML 内容（xhtml 文件）
- 提取嵌入图片、CSS 样式表、字体

**写入**
- 生成合法 EPUB 3 文件（`mimetype` + `META-INF/container.xml` + OPF + XHTML + ZIP）
- 写入元数据和目录、添加章节（XHTML 内容）
- 嵌入封面图片和基础 CSS

---

### 3.13 XP — XPS 固定版式文档（.xps / .oxps）

**读取**
- 解析 XPS 文件结构（ZIP + `/Documents/1/FixedDocumentSequence.fdseq`）
- 提取各页面 XAML（FixedPage）、文本内容提取（`Glyphs` 元素 → 文本字符串）
- 图片提取（嵌入 PNG/JPEG 资源）、提取页面尺寸/页数

**写入**
- 生成最小合法 XPS/OXPS 文件
- 写入文本（单一字体，无复杂布局）、插入图片、写入元数据（标题/作者）

---

### 3.14 REN — Rendering 渲染扩展包

NewLife.Office.Rendering 是独立的 NuGet 扩展包（依赖 SkiaSharp），提供文档页面渲染为图片、图片处理、二维码生成等能力。

**文档 → 图片渲染**
- PDF 单页/全页 → PNG/JPEG（基于 SkiaSharp Canvas 渲染管线）、多格式输出（PNG/JPEG/WebP/BMP）
- DOCX 单页/全页 → PNG（docx→PDF 中转）、PPTX 幻灯片 → PNG（pptx→PDF 中转）
- Markdown 文本/文件 → PNG（MD→PDF 中转）

**图片处理工具**
- 图片缩放（保持宽高比）、格式转换（PNG/JPEG/WebP/BMP 互转）
- 裁剪/旋转、文字水印（透明度 + 位置控制）、图片叠加（透明度 + 位置控制）
- 文字 → 图片（多行 + 自动换行 + 字体指定）、二维码 → 图片（指定颜色和格式）

**高级渲染**
- PDF 缩略图网格（多页拼图，失败页灰色占位）
- 综合文档预览（`DocumentPreview.RenderFirstPage()` 自动按扩展名路由）

### 3.15 GEN — 通用（跨格式）

**内容识别（GEN-1，对标 anydoc）**
- `OfficeFactory.Detect()`：按文件头 magic bytes 识别格式（PDF/RTF/OLE2/ZIP 容器/文本类），不依赖扩展名
- `OfficeFactory.CreateReaderByContent()`：扩展名错误/缺失时仍按内容正确读取，为统一入口兜底

**CLI 工具链（GEN-2，对标 anydoc CLI/Agent Skill）**
- `NewLife.Office.Cli` 命令行工具：`convert` 子命令实现任意办公文档 → Markdown/HTML 转换
- 内容识别 + 格式路由自动选择 Reader/Converter，零外部依赖，可被 Agent/脚本直接调用

## 4. 🧊 暂缓清单

| 功能 | 暂缓理由 | 解冻前提 |
|------|----------|----------|
| PPT 幻灯片渲染为图片（S09-02/S15-05） | 需外部渲染库（SkiaSharp/Docnet.Core），与主库零依赖定位冲突 | 已由 Rendering 扩展包承接，主库不再内置 |
| PDF 页面渲染为图片（P07-05） | 同上 | 已由 Rendering 扩展包承接 |
| Word 页面渲染为图片（W08-04） | 同上 | 已由 Rendering 扩展包承接 |
| LibreOffice 集成（W08-05） | 外部依赖（soffice headless），与零依赖定位冲突 | 需要像素级高保真转换时再评估 |
| MSG 写入 | 需求极少 | 邮件系统需要生成 .msg 时 |
| ODP（OpenDocument Presentation） | 独立格式规划，当前优先级低 | 用户明确需要演示文稿 ODF 支持时 |
| PPT 完整动画时间轴/自定义路径 | 规范极复杂，已实现基础三类动画 | 高级动画场景需求出现时 |
| Excel 公式计算引擎 | 实现复杂，公式读写已支持 | 需要公式求值场景时 |

## 5. 不做什么

明确排除的功能项，避免后续争议。

| 功能 | 原因 |
|------|------|
| CSV 读写 | 已由 NewLife.Core `CsvFile` 提供，不重复实现 |
| Excel 公式计算引擎 | 实现复杂，公式读写已支持，无内置计算引擎 |
| Excel VBA/宏 | 安全与复杂度问题 |
| Word 修订追踪接受/拒绝操作 | 实现复杂、场景有限；读取模型（W11）已实现 |
| Word/PPT ActiveX 控件 | 安全问题 |
| PPT SmartArt 创建/编辑 | 实现极复杂，需商业级实现；透传读写保持文件完整性 |
| PPT 完整动画时间轴/自定义路径 | 规范极复杂，优先实现基础进入/退出/强调三类动画 |
| PPT → PPTX 格式转换 | 需深度解析 MS-PPT 二进制格式，ROI 低 |
| PPT 3D 效果/形状特效 | 纯装饰性，规范复杂，场景有限 |
| PPT VBA 宏（pptm） | 安全与复杂度问题 |
| PPT 数学公式（OfficeMath） | 依赖 MathML 渲染，与 Word 模块不共享实现 |
| ODP（OpenDocument Presentation） | 格式独立规划，当前优先级低 |
| HTML→PDF 高保真转换 | 需要完整渲染引擎/浏览器，体积不可控 |
| PDF OCR 文字识别 | 需引入专业 OCR 服务，与本库定位不符 |
| doc 格式写入（97-2003） | 需求极少，格式已淘汰 |

# Office 文档往返测试加固 — 功能清单

> 最后更新：2026-07-03

## 核心目标

五大主流文档（PPTX/DOCX/XLSX/PDF/Markdown）的读写读往返测试：
- 读取真实文件 → 解析为完整对象模型 → Writer 重建文件 → 再次读取 → 新旧模型深度逐属性精确对比
- 禁止弱断言：禁止仅判集合数量相等、禁止仅判非空即通过
- String/基础类型维度必须精确相等
